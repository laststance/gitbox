# Security Policy

## Supported Versions

We provide security updates for the latest version on the `main` branch.

## Reporting a Vulnerability

If you discover a security issue, please report it privately.

- Email: ryota.murakami@laststance.io
- Include: a clear description, steps to reproduce, affected components, and
  any relevant logs or screenshots.

## Response Process

We aim to acknowledge reports within a few business days and will provide a
status update after the initial triage. If the report is accepted, we will
work on a fix and coordinate a disclosure timeline with you.

## Public Disclosure

Please do not publicly disclose the issue until we have confirmed a fix or
agreed on a disclosure date.
